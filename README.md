# Hilton Hotels Clone 🏨

A functional Hilton Hotels-like hotel booking web application built as part of CWI Task 39.

## 🎯 Project Objective

The goal of this project is to develop a functional hotel booking platform where users can search for hotels, view hotel details, and book hotel rooms.

## ✨ Features

- 🏠 Responsive homepage
- 🔍 Hotel search by location
- 📅 Check-in and check-out date selection
- 🏨 Hotel listing page
- 🖼️ Hotel images and descriptions
- ⭐ Hotel ratings and reviews
- 💰 Hotel pricing
- 🔎 Price, rating, and amenities filters
- ↕️ Hotel sorting
- 📋 Hotel details page
- 🛎️ Hotel booking system
- 💾 SQLite database for storing hotel and booking data
- ✅ Booking confirmation page
- 📖 My Bookings page
- 🗑️ Delete booking functionality
- 📱 Responsive design for desktop and mobile
- 🎁 Offers page
- ℹ️ About page
- 🔐 Sign In demo page

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- SQLite3
